# Internet use grew at different speeds across countries and areas

## A fixed comparison, not a world average

How much did Internet use change in places with observations at both ends of the 2000–2024 period? In a matched set of 175 country-or-area entities selected against the UN M49 reference, the middle change was 67.9 percentage points. The central half of the entity-level changes ran from 50.9 to 81.1 points.

These are percentage-point changes in the population share reporting recent Internet use, not percentage growth. The distribution gives every included entity equal weight; it is not weighted by population.

### Middle half of 2000–2024 changes

| Cohort position | Change in share using the Internet |
| --- | ---: |
| 25th percentile | 50.9 percentage points |
| Median | 67.9 percentage points |
| 75th percentile | 81.1 percentage points |

**Visual treatment for future rendered article:** one horizontal interval from the 25th to 75th percentile with a median marker, labelled “175 matched country-or-area entities” and “percentage-point change, 2000–2024.” Do not imply a population-weighted range or show unapproved extrema.

The source indicator counts a person as an Internet user if they used the Internet from any location in the preceding three months. It does not measure connection speed, quality, affordability, or task usefulness. A fixed endpoint cohort makes the comparison consistent, but leaves out places without both observations and does not explain why their changes differed.
